# Política de Segurança e Divulgação Responsável — BaixALL

Levamos a segurança e a privacidade a sério no projeto **BaixALL**. Agradecemos a colaboração da comunidade de segurança e dos usuários na identificação responsável de vulnerabilidades.

---

## 🛡️ 1. Versões com Suporte de Segurança

Atualmente, apenas as seguintes versões recebem atualizações de segurança:

| Versão | Suporte a Correções de Segurança |
| :--- | :--- |
| **1.3.x (Última versão estável)** | :white_check_mark: Ativo |
| Versões Anteriores / Release Candidates | :x: Encerrado (atualize para a versão estável mais recente) |

---

## 🔒 2. Como Relatar uma Vulnerabilidade de Forma Segura

> ⚠️ **IMPORTANTE:**  
> **NÃO abra Issues públicas no GitHub para relatar potenciais vulnerabilidades de segurança ou falhas que possam colocar usuários em risco.**  
> Relatórios públicos expõem outros usuários antes que uma correção possa ser desenvolvida e disponibilizada.

### Canal Recomendado: GitHub Private Vulnerability Reporting
O GitHub oferece uma ferramenta nativa, segura e confidencial para submeter alertas de segurança diretamente aos mantenedores do projeto:

1. Acesse a aba **Security** do repositório no GitHub:  
   👉 [https://github.com/ArkanjoV2/BaixALL/security](https://github.com/ArkanjoV2/BaixALL/security)
2. Clique na seção **"Advisories"** (ou [Report a vulnerability](https://github.com/ArkanjoV2/BaixALL/security/advisories/new)).
3. Preencha o formulário confidencial descrevendo o problema, passos para reprodução e impacto potencial.
4. Esse canal é totalmente privado e visível apenas para você e o mantenedor do repositório (`ArkanjoV2`).

---

## 📋 3. O que Esperar do Nosso Processo

- **Confirmação:** Nos esforçamos para acusar o recebimento do relato inicial em até 48 horas úteis.
- **Avaliação:** Investigaremos a causa técnica e o escopo do impacto.
- **Correção:** Trabalharemos em uma correção de segurança em branch privada.
- **Divulgação Coordenada:** Assim que uma nova versão estável contendo a correção for publicada, o aviso de segurança poderá ser tornado público com os devidos créditos aos pesquisadores que colaboraram.
